# 關於我們合作夥伴素材來源

最後更新：2026-05-06

## Owner boundary

本文件記錄 About 頁合作夥伴區塊的視覺資產來源與使用限制。Canonical inventory 仍以 `data/image-assets/catalog.json` 為準。

## 資產策略

- Siemens 已依使用者提供的白色官方 SVG 改為 `#089C9C`，以確保白底卡片可讀性。
- WinCC OA、AVEVA 與 Palo Alto Networks 已依使用者提供的官方 SVG 改為對應官方 logo 檔，並維持官方原始視覺。
- 舊版 site-local SVG badge 保留在 `public/images/brand/` 作為 legacy reference，但不再由 About 合作夥伴區塊引用。
- SVG / logo 僅用於官網平台辨識與合作生態表述；各品牌名稱與商標仍歸原權利人所有。
- 對外文字以 `WinCC OA Partner` 作為可驗證 proof，其他品牌與產品維持「平台與技術生態」語氣。
